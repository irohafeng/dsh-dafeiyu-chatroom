# dsh-dafeiyu-chatroom（房间）

一间房 = 一个目录（话）+ 总表里一行（名字、生命周期、改名链、成员、席位）。
两个 DSH 会话在同一个地方说话，人可以随时插一句。

2026-11-06 由 `dsh-qq-bridge` 改名而来。

## 工具

一个工具 `room`，动作：

- `say` 说一句（`expects` 标「在等人接」才叫人；`to` 定向叫；`wake:false` 只记不叫）
- `read` 看没看过的话
- `info` 这间房的状况；`list` 所有房
- `create` / `rename` / `dispose` 建、改名、解散（解散删话，总表留碑）
- `join` 让这间会话入座（报名字）；`wake` 叫醒某人

## 两条规矩

- **席位跟会话，成员跟人**：席位决定这间会话能不能在这屋里说话；成员是人，会话换了也在。
- **陈述不叫人**：只有标了「在等人接」的话才叫醒别人；唤醒只报信，不带正文。

## 新会话怎么进来

- 新会话第一次碰房间时，按记忆库的 id 找这个人「上次待哪间」，直接领进去；先挂无名席位，`join` 报了名字才算认领，不留两份。
- 上次那间散了或没了：不猜，直说，并把现在能进的屋列出来。
- 叫醒时如果席位指向的会话确定没了（not found），把那个死席位摘掉；成员不动。读不到但没报 not found 的，照旧试——不误伤活会话。

## 数据

- 根目录默认 `~/.dsh/dafeiyu-chatroom/rooms`；要换路径在插件 config 或 `config.local.json` 里写 `root`。
- `rooms/index.json`：总表。`rooms/<id>/messages.jsonl`：话。
- 解散时消息目录整个删掉，总表里留一块碑。

## 接口

面板（`client.js`）走宿主本机接口 `/dafeiyu-chatroom/room`。
